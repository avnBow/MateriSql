Pengenalan SQL,
Database & Tabel

Mulai dari membuat ruang penyimpanan (Database), menyusun strukturnya (Tabel), hingga menyimpan rekaman data di dalamnya.

Tujuan pembelajaran

  • Memahami konsep dasar Relational Database.
  • Menggunakan perintah CREATE DATABASE.
  • Membuat kerangka penyimpanan dengan CREATE TABLE beserta tipe datanya.
  • Memasukkan data menggunakan INSERT INTO.
01 • Penjelasan singkat

Apa itu Database & Tabel?

Database adalah lemari arsip, Tabel adalah laci penyimpanannya.

Struktur Penyimpanan Data

Dalam SQL (Structured Query Language), data disimpan dalam Database. Di dalam database, terdapat Tabel yang terdiri dari baris (record) dan kolom (field). Sebelum kita bisa memasukkan data, kita harus menyiapkan wadah (database) dan strukturnya (tabel) terlebih dahulu.

-- Membuat database baru CREATE DATABASE nama_database; -- Menentukan database yang akan digunakan USE nama_database;

Pada modul ini, kode dapat dicoba langsung melalui tombol Jalankan. Kode ini akan dijalankan langsung oleh mesin SQLite WebAssembly. Dalam dunia nyata, Anda akan menjalankan perintah ini di aplikasi seperti XAMPP (phpMyAdmin) atau DB Browser.

Konsep inti

Tipe Data SQL

Setiap kolom dalam tabel wajib memiliki tipe data untuk membatasi nilai yang masuk.

CREATE TABLE

Membuat struktur kolom beserta tipe datanya.

CREATE TABLE Siswa ( id INT PRIMARY KEY, nama VARCHAR(50) );

INSERT INTO

Memasukkan data (record) ke dalam tabel.

INSERT INTO Siswa (id, nama) VALUES (1, 'Budi Santoso');
Tipe Data Contoh Nilai Kegunaan
INT 1, 250, 9999 Angka bulat. Cocok untuk ID, jumlah, harga bulat.
VARCHAR(n) 'Restu', 'Jl. Mawar' Teks pendek, panjang maksimal n karakter.
TEXT 'Artikel panjang...' Teks sangat panjang seperti deskripsi/artikel.
DATE '2024-05-12' Menyimpan tanggal (Format: YYYY-MM-DD).
