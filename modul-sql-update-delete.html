Mengubah & Menghapus Data
(UPDATE & DELETE)

Data tidak selamanya statis. Terkadang ada kesalahan ketik atau data yang sudah tidak relevan. Mari pelajari cara memanipulasi data yang sudah ada di dalam tabel.

Tujuan pembelajaran

  • Memahami bahaya query tanpa kondisi (WHERE).
  • Mengubah nilai data spesifik menggunakan perintah UPDATE.
  • Menghapus record tertentu menggunakan perintah DELETE.
  • Mengeksekusi query secara aman menggunakan aplikasi CLI/DB Browser.
01 • Penjelasan singkat

Modifikasi Data Lanjutan

Aturan Emas: Jangan pernah melupakan WHERE saat melakukan UPDATE atau DELETE!

UPDATE

Digunakan untuk mengubah data yang sudah ada di dalam tabel. Kamu menggunakan klausa SET untuk menentukan kolom mana yang akan diubah.

-- Contoh: Mengubah pengarang buku ber-ID 1 UPDATE Buku SET pengarang = 'Penulis Baru' WHERE id = 1;

Peringatan: Jika kamu lupa menuliskan WHERE id = 1, maka SELURUH buku di tabel akan berubah nama pengarangnya!

DELETE

Digunakan untuk menghapus satu atau beberapa baris data (record) secara permanen dari dalam tabel.

-- Contoh: Menghapus buku dengan kode tertentu DELETE FROM Buku WHERE nomor_buku = 'B-099';

Peringatan: Sama seperti UPDATE, jika kamu hanya menulis DELETE FROM Buku;, maka semua data di tabelmu akan musnah.

02 • Praktikum

Praktik Eksekusi Langsung

Buka file latihan.sqlite menggunakan DB Browser for SQLite atau CLI, lalu ketik dan jalankan query berikut. Setelah selesai dieksekusi, periksa perubahan datanya dengan melakukan SELECT * FROM Buku;

1

Update berdasarkan ID

ID (Primary Key) adalah patokan paling aman untuk melakukan update karena sifatnya unik. Mari kita ubah judul buku untuk ID ke-1.

-- Mengubah judul buku Laskar Pelangi menjadi versi revisi UPDATE Buku SET judul_buku = 'Laskar Pelangi (Edisi Revisi)' WHERE id = 1;
2

Update berdasarkan Nomor Buku

Kamu juga bisa melakukan update menggunakan acuan unik lainnya selain ID, misalnya menggunakan Nomor Buku.

-- Mengubah judul buku untuk nomor_buku B-005 UPDATE Buku SET judul_buku = 'Cantik Itu Luka (Special Edition)' WHERE nomor_buku = 'B-005';
3

Delete berdasarkan ID

Jika ada buku yang rusak atau ditarik dari peredaran, kita bisa menghapusnya dari database.

-- Menghapus baris data yang memiliki ID 10 DELETE FROM Buku WHERE id = 10;
4

Delete berdasarkan Pengarang (Mass Delete)

Menghapus menggunakan klausa nama (seperti pengarang) dapat menghapus banyak data sekaligus jika pengarang tersebut memiliki lebih dari satu buku.

-- Menghapus SEMUA buku karangan 'Pidi Baiq' (B-016 & B-017) DELETE FROM Buku WHERE pengarang = 'Pidi Baiq';
Penting untuk DB Browser! Setelah menjalankan perintah UPDATE dan DELETE, jangan lupa menekan tombol Write Changes (atau Ctrl+S) agar datanya tersimpan ke file SQLite secara permanen!
