Menampilkan Data
(Query SELECT)

Setelah membuat tabel dan mengisinya dengan data, saatnya belajar bagaimana cara memanggil, menyaring, dan mengurutkan data dari tabel tersebut.

Tujuan pembelajaran

  • Menggunakan perintah SELECT untuk memanggil semua data.
  • Menyaring data spesifik (WHERE) & pencarian pola (LIKE).
  • Mengurutkan data menggunakan ORDER BY (ASC & DESC).
  • Membatasi jumlah data yang tampil dengan LIMIT.
01 • Penjelasan singkat

Perintah SELECT

SELECT adalah perintah paling sering digunakan dalam basis data.

Struktur Dasar Pengambilan Data

Gunakan simbol * (bintang/asterisk) untuk mengambil semua kolom dari suatu tabel, atau sebutkan nama kolomnya satu per satu jika hanya butuh data tertentu.

-- Menampilkan seluruh kolom dan baris dari tabel Buku SELECT * FROM Buku; -- Menampilkan HANYA kolom judul dan pengarang SELECT judul_buku, pengarang FROM Buku;
Konsep inti

Menyaring & Mengurutkan

Database besar butuh filter agar data yang dipanggil relevan dengan kebutuhan.

WHERE & LIKE

Digunakan untuk memberi kondisi/syarat. LIKE digunakan mencari pola teks (dilengkapi simbol %).

-- Data berdasarkan kode spesifik SELECT * FROM Buku WHERE nomor_buku = 'B-001'; -- Data pengarang yang mengandung nama 'Andrea' SELECT * FROM Buku WHERE pengarang LIKE '%Andrea%';

ORDER BY & LIMIT

ASC mengurutkan dari A-Z, DESC dari Z-A. LIMIT membatasi jumlah tampilannya.

-- Mengurutkan judul menurun (Z ke A) SELECT * FROM Buku ORDER BY judul_buku DESC; -- Menampilkan 10 data teratas saja SELECT * FROM Buku LIMIT 10;
